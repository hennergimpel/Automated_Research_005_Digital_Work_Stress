# Automated Research 005: Digital Work Stress

This repository holds the prospective analysis plan and, as they become available, replication materials for a new study using the open data accompanying Gimpel et al. (2025), *Stress from Digital Work: Toward a Unified View of Digital Hindrance Stressors*.

## Prospective plan

[Read the complete analysis plan](prospective-analysis-plan.md). It includes the theory, measurement decisions, exact analysis specification, precision scenarios, source versions, and exposure disclosure. The initial plan is posted before the new study's tests. The [initial plan commit](https://github.com/hennergimpel/Automated_Research_005_Digital_Work_Stress/commit/20b0cd92de4a08f0b47649183cef92e690026ef6) records the prospective specification at 2026-10-23 07:42:49 UTC. [SHA256SUMS.txt](SHA256SUMS.txt) identifies current file bytes. The current edition has editorial changes to posting administration only; the scientific specification is unchanged.

This is a prospectively posted GitHub plan. It is not an OSF registration or an independently immutable registry. Earlier technical work tested data access and analytics software; it did not develop or test this new study's hypotheses. The plan discloses the historical technical processing.

## Data and replication

The original data are available from [the authors' OSF repository](https://osf.io/7yjq4/) (DOI: 10.17605/OSF.IO/7YJQ4). Exact file/version/hash and attribution are documented in the plan. Participant-level data are not redistributed here.

The [replication archive](replication-package.zip) contains the standalone analysis code, specification, source-access instructions, and aggregate outputs. See [RELEASE_STATUS.md](RELEASE_STATUS.md) for the current release status, [REPLICATION.md](REPLICATION.md) for execution instructions and [public_file_manifest.json](public_file_manifest.json) for file hashes and exclusions. The archive requires the separately obtained, version-pinned source CSV; participant-level data are not included.

The [workflow transparency supplement](workflow-transparency.md) describes the research process, representative task prompts, verification and known record limitations. These are process summaries, not complete interaction logs.

The intended venue is the [ICIS 2026 PDW on Autonomous Scholarship](https://sites.nd.edu/autonomous-workshop/). Repository creation and plan posting do not constitute paper submission or acceptance.
