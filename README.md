# Automated Research 005: Digital Work Stress

This repository holds the prospective analysis plan and, as they become available, replication materials for a new study using the open data accompanying Gimpel et al. (2025), *Stress from Digital Work: Toward a Unified View of Digital Hindrance Stressors*.

## Prospective plan

[Read the complete analysis plan](prospective-analysis-plan.md). It includes the theory, measurement decisions, exact analysis specification, precision scenarios, source versions, and exposure disclosure. The initial plan is posted before the new study's tests. Its original bytes are identified in [SHA256SUMS.txt](SHA256SUMS.txt); use the initial plan commit when referring to the prospective specification.

This is a prospectively posted GitHub plan. It is not an OSF registration or an independently immutable registry. Earlier technical work tested data access and analytics software; it did not develop or test this new study's hypotheses. The plan discloses the historical technical processing.

## Data and replication

The original data are available from [the authors' OSF repository](https://osf.io/7yjq4/) (DOI: 10.17605/OSF.IO/7YJQ4). Exact file/version/hash and attribution are documented in the plan. Participant-level data are not redistributed here.

Replication code, source-access instructions, permitted aggregate outputs, deviations, and workflow transparency materials will be added after analysis and verification. No study findings are claimed in this initial posting.

The intended venue is the [ICIS 2026 PDW on Autonomous Scholarship](https://sites.nd.edu/autonomous-workshop/). Repository creation and plan posting do not constitute paper submission or acceptance.
